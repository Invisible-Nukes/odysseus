## Completed Work

### Phase 1: launch-windows.ps1 pip hardening ✅

**Problem:** Launcher failed at step 3 — corrupted pip cache (`IncompleteRead` on `soupsieve` wheel) left venv incomplete (no `uvicorn`).

**Fix (commit `22c12d2`):**
- `Test-OdysseusDepsReady` — skip pip when `uvicorn` + `sqlalchemy` importable
- `Install-OdysseusDependencies` — `--retries 5 --timeout 120`, up to 3 attempts, auto `pip cache purge` on cache corruption errors

**Verified:** Full launcher run; HTTP 200 on `:7000`; deps skip on re-run.

### Phase 2: ChromaDB native Windows bootstrap ✅

**Problem:** ChromaDB not started on Windows native path (Docker/macOS only); app logged `ChromaDB is not reachable at localhost:8100` — vector RAG/memory degraded.

**Fix (commit `b258f50`):**
- `Ensure-ChromaDbPackage` — install `chromadb` into venv if missing; skip with message when `chroma.exe` / `pip show chromadb` present
- `Start-OdysseusChromaDb` — bind `127.0.0.1:8100`, persist to `data/chroma`
- `Stop-OdysseusChromaDb` — `taskkill /T` in `finally` when launcher exits
- Sets `CHROMADB_HOST` / `CHROMADB_PORT` defaults

**Verified:** Log line `ChromaDB connected: localhost:8100`; heartbeat OK on `:8100`.

### Phase 3: Cookbook llama-cpp-python diagnosis ✅

**Finding:** `llama-cpp-python[server]` Cookbook dependency task fails on this VM — no Py3.13 Windows CPU wheel; source tarball extract fails (Windows Long Paths disabled); no cmake/MSVC. **Recommendation:** use Ollama (already under `data/ollama`).

Not a Jun 25 path-contract regression.
