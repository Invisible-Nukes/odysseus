## Hardening Changes
| Change | Mechanism | Effect |
|---|---|---|
| PATH sanitization | Remove specific `%LOCALAPPDATA%` interpreter/bin entries at script start | Reduces accidental Hermes/stray Python/Git Bash inheritance |
| Exact venv Python match | `Resolve-Path` compare against `odysseus\venv\Scripts\python.exe` | Flags only Odysseyus venv Python in process matcher |
| Command-line scoping | Require `uvicorn|app:app`, exact venv py, or escaped repo-root fallback | Reduces false positives |
| Browser-open readiness probe | Wait for HTTP 302 from `http://127.0.0.1:7000/` | Prevents premature browser launch |
| `conftest.py` stub | Conditional `src.database` import path/webhook stub | Prevents test collection import crash |
