## 2. Root-Cause Findings

- **Public PyPI 10054**: Python urllib/pip/curl deterministically reset by PyPI edge on this host; PowerShell `Invoke-WebRequest` succeeds. Verified against `tuna` and `aliyun` mirrors in isolation.
- **Sitecustomize import error**: Generated `sitecustomize.py` lacked `import sys`, causing `NameError` at venv startup and contaminating `sys.path`.
- **Missing function**: `Test-IsHermesAgentPython` was called but never defined, causing immediate script abort.
- **Unconditional success message**: `Dependencies installed successfully` printed before verifying packages actually landed in venv.
- **Wrapper exit code**: `4294967295` reported by Hermes terminal wrapper, not produced by script logic.

## 6. Lessons Learned

1. **Root-cause wrapping**: when a working workaround exists, do not build increasingly elaborate fallback logic. Use the working solution directly.
2. **Subagent self-report is not verification**: always verify runtime state yourself with live runs.
3. **End-to-end early**: syntax validation alone is insufficient. Run reset → launch → import check in one cycle early.
4. **Subagent fan-out discipline**: do not spin up 3 parallel subagents for linear problems. The bottleneck is live verification.
5. **Stop whack-a-mole**: if each live run surfaces exactly one new bug, do a fuller static pass first.
6. **Verification criteria**: for PowerShell scripts, AST parse is necessary but not sufficient. The real verification is: did the script complete its actual job?
